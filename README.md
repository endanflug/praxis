# Endanflug

**Praxiswissen aus dem Cockpit – aus Sicht eines Line Training Captains.**

Handbücher erklären, *was* zu tun ist. Hier geht es darum, *wie* man es tut:
die Techniken, Denkweisen und kleinen Kniffe, die im Line Training von Kapitän
zu Kapitän weitergegeben werden, aber so in keinem Buch stehen.
